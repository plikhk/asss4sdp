## Описание проекта
Этот проект демонстрирует реализацию структурного паттерна проектирования **Facade** на языке Java. 

В качестве предметной области выбрана система обработки онлайн-заказов (Online Order Processing). Процесс оформления и отмены заказа включает взаимодействие нескольких сложных подсистем: проверки запасов, обработки платежей, организации доставки и отправки уведомлений. 

Паттерн `OrderFacade` предоставляет упрощенный API (`placeOrder` и `cancelOrder`) для клиентского кода, скрывая всю сложность оркестрации подсистем и логику откатов (rollbacks) в случае ошибок транзакций (например, отмена резерва на складе при сбое оплаты).

## Структура проекта
Проект разделен на пакеты для четкого разделения ответственности:

*   `models/`: Классы данных (`Cart`, `Customer`, `Order`).
*   `subsystem/`: Классы сложной подсистемы со своей внутренней логикой:
    *   `InventoryService` (Управление запасами)
    *   `PaymentProcessor` (Обработка платежей)
    *   `ShippingService` (Организация доставки)
    *   `NotificationService` (Уведомления клиентов)
*   `facade/`: Содержит класс `OrderFacade`, который координирует работу подсистем.
*   `client/`: Содержит класс `Main`, демонстрирующий работу с Фасадом.

## Как запустить проект

1.  Убедитесь, что у вас установлена Java Development Kit (JDK) версии 17 или выше.
2.  Склонируйте репозиторий:
    ```bash
    git clone [ссылка на ваш репозиторий]
    ```
3.  Откройте проект в IntelliJ IDEA (или другой совместимой IDE).
4.  Перейдите в файл `src/client/Main.java`.
5.  Запустите класс `Main` (Run 'Main.main()').
6.  В консоли вы увидите пошаговый процесс оформления и отмены заказа, демонстрирующий работу подсистем через Фасад.

## Принципы чистого кода (Clean Code)
В проекте применены следующие принципы:
1.  **Meaningful Names**: Методы фасада имеют четкие намерения (`placeOrder`).
2.  **Single Responsibility**: Фасад только координирует, подсистемы выполняют узконаправленную работу.
3.  **No Leaking**: Клиент (`Main`) работает только с простыми моделями данных, не зная о деталях подсистемы.
